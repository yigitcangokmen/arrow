# Judges: claim, code, test, command

One row per claim. Find the code that does it, the test that checks it and the command that shows it. Run every command from the repository root.

## How to read

- **PROVEN**: the command or transaction in the row shows it today. A parenthesis says where (native test, testnet, mainnet, sandbox).
- **NOT PROVEN** and **RISKY**: we do not claim it (NOT PROVEN) or it is true and a weakness (RISKY). Each of these rows says why. NOT PROVEN is never counted as passed.
- `TODO(K4)` and `TODO(K5)` mark mainnet slots that are filled from recorded evidence after the Arrow program runs on mainnet (K4) and after the lock (K5). Until then the row is NOT PROVEN for mainnet and the testnet evidence is named in the row.

`npm run check:judges` checks that every path and test name below exists.
