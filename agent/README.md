# agent/ (@arrow/agent)

The agent path, for buyers that are programs rather than people.
- CLI `arrow eval <listing_id> --criteria <file> --network <testnet|mainnet>` and `arrow buy`.
- MCP server `arrow`, tool `inspect_before_buy` (`@modelcontextprotocol/sdk` 1.32.2).

Demo purchase #1 is made from here with the public demo viewing key (KICKOFF.md §2.7).
Add a `bin` entry to package.json only once the entry files exist; otherwise `npm ci` fails on missing bin targets.
